# 🤖 SOKOLOV BOTS Маркетплейс tg ботов

Веб-приложение на Go для покупки и продажи готовых tg ботов. Разработчики могут публиковать своих ботов в виде ZIP-архивов, а предприниматели просматривать каталог и покупать понравившихся ботов

## 🚀 Функциональность

- **Регистрация и авторизация** - безопасное хеширование паролей через bcrypt
- **Каталог ботов** - просмотр всех доступных предложений
- **Страница товара** - подробная информация, ссылка на GitHub, контакт продавца
- **Загрузка файлов** - добавление бота в виде ZIP-архива
- **Личный кабинет** - управление своими объявлениями (просмотр и удаление)
- **Скачивание** - получение архива с кодом бота

##  Технологический стек

| Компонент | Технология |
|-----------|-----------|
| Язык | Go (Golang) |
| Роутинг | chi |
| База данных | SQLite |
| Хеширование паролей | bcrypt (golang.org/x/crypto) |
| Шаблоны | html/template (встроенный в Go) |
| Стилизация | Tailwind CSS (через CDN) |

## 📁 Структура проекта


## ⚙️ Как запустить локально

### Требования
- Go 1.21+
- Git

### Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/SOKOLOV8080/SOKOLOV_BOTS_beta1.0.git
cd SOKOLOV_BOTS_beta1.0
```

2. Установите зависимости:
```bash
go mod tidy
```

3. Создайте папку для загрузок:
```bash
mkdir uploads
```

4. Запустите сервер:
```bash
go run cmd/web/main.go
```

5. Откройте в браузере: **http://localhost:8080**

## 🔐 Безопасность

- Пароли хешируются алгоритмом **bcrypt** с автоматической солью
- SQL-инъекции предотвращены через параметризованные запросы
- XSS-атаки блокируются встроенной экранизацией `html/template`
- Удаление товаров доступно только их владельцу (проверка `seller_id`)
